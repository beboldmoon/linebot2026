# 신규생성 예시 그림

신규생성 카테고리에서 장소 카드의 **그림 고르기**로 바로 쓸 수 있는 그림입니다.
모두 440×440 투명 배경 PNG이고, 넣으면 긴 변 220px로 자동 축소됩니다.
