# 핑퐁 라인봇 시뮬레이터 (linebot2026)

컬러 스티커로 로봇의 길을 프로그래밍하는 언플러그드 코딩 학습 도구입니다.
설치 없이 브라우저에서 바로 실행됩니다.

## 사용법

지도 위 점선 네모 칸을 탭하면 색이 순서대로 바뀝니다. 색을 배치한 뒤 **출발**을 누르면 로봇이 주행합니다.

| 색 | 명령 | 동작 |
|---|---|---|
| 🟠 주황 | 출발 | 0.5초 멈췄다 출발, 다음 컬러 1개 무시 |
| 🟢 연두 | 멈춤 | 만나면 그 자리에 정지 |
| 🔴 빨강 | 오른쪽 | 다음 교차로에서 우회전 |
| 🔵 파랑 | 왼쪽 | 다음 교차로에서 좌회전 |
| 🟡 노랑 | 유턴 | 왔던 길로 되돌아가기 |

## 지도

- **동네** — 용산역, 국립중앙박물관, N서울타워, 용문시장, 한강공원, 용산전자상가
- **세계** — 몽골 게르, 베트남 수상가옥, 필리핀 니파집, 캐나다 이글루, 네덜란드 풍차집, 미국 인디언텐트
- **연습** — 가게 없는 격자 맵

각 지도마다 별 1~3개의 난이도가 있고, 갈림길 수가 늘어납니다.

## 버튼

- **출발** — 처음 위치로 되돌린 뒤 주행 시작
- **처음** — 로봇을 출발점으로 (스티커는 유지)
- **지우기** — 현재 지도의 스티커 전체 삭제
- **PDF** — 현재 지도를 B3(500×353mm) 가로 PDF로 저장. 인쇄해서 실물 수업에 사용
- **속도 슬라이더** — 주행 속도 조절
- **그림 기호 on/off** — 색 위의 화살표 기호 표시 전환

## 실행

`index.html`을 브라우저로 열면 됩니다. PDF 저장 기능만 인터넷 연결이 필요합니다(jsPDF CDN).
