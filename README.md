# 핑퐁 라인봇 시뮬레이터 (linebot2026)

컬러 스티커로 로봇의 길을 프로그래밍하는 언플러그드 코딩 학습 도구입니다.
설치 없이 브라우저에서 바로 실행됩니다.

## 사용법

지도 위 점선 네모 칸을 탭하면 색이 순서대로 바뀝니다. 색을 배치한 뒤 **출발**을 누르면 로봇이 주행합니다.

| 색 | 명령 | 동작 |
|---|---|---|
| 🟠 주황 | 출발 | 0.5초 멈췄다 출발, 다음 컬러 1개 무시 |
| 🟢 연두 | 멈춤 | 만나면 그 자리에 정지 |
| 🔴 빨강 | 오른쪽 | 다음 교차로에서 우회전 |
| 🔵 파랑 | 왼쪽 | 다음 교차로에서 좌회전 |
| 🟡 노랑 | 유턴 | 왔던 길로 되돌아가기 |

## 지도

- **동네** — 용산역, 국립중앙박물관, N서울타워, 용문시장, 한강공원, 용산전자상가
- **세계** — 몽골 게르, 베트남 수상가옥, 필리핀 니파집, 캐나다 이글루, 네덜란드 풍차집, 미국 인디언텐트
- **연습** — 가게 없는 격자 맵
- **신규생성** — 장소 이름과 그림을 직접 넣어 쓰는 빈 지도

각 지도마다 별 1~3개의 난이도가 있고, 갈림길 수가 늘어납니다.

## 신규생성 카테고리

수업 주제에 맞는 지도를 직접 만들 수 있습니다.

점선으로 표시된 빈 카드를 탭하면 편집창이 열립니다. **이름**(최대 10자)과 **그림**(이미지 파일)을 넣고 저장하면 지도에 반영됩니다. 이름과 그림을 모두 비우고 저장하면 다시 빈 카드로 돌아갑니다.

단계마다 장소가 따로 저장되고, 개수는 난이도에 따라 정해집니다.

| 난이도 | 장소 수 |
|---|---|
| ★ | 3곳 (위 1, 아래 1, 도착지 1) |
| ★★ | 5곳 (위 2, 아래 2, 도착지 1) |
| ★★★ | 7곳 (위 3, 아래 3, 도착지 1) |

넣은 그림은 긴 변 220px로 자동 축소되어 브라우저에 저장됩니다. 같은 브라우저에서는 새로고침해도 유지되지만, 기기나 브라우저가 바뀌면 다시 넣어야 합니다. 다른 컴퓨터에서도 같은 지도를 쓰려면 아래 내보내기를 사용하세요.

### 예시 그림

바로 쓸 수 있는 투명 배경 그림을 [`examples/`](examples/) 폴더에 넣어 두었습니다 — 동네 장소 12개(학교, 병원, 소방서 등)와 세계 랜드마크 20개(에펠탑, 피라미드, 숭례문 등).

### 내보내기 / 불러오기

신규생성 카테고리를 고르면 하단에 **내보내기**와 **불러오기** 버튼이 나타납니다.

- **내보내기** — 세 단계의 장소를 `라인봇_신규생성_날짜.json` 파일 하나로 저장합니다. 그림도 파일 안에 함께 들어가므로 이 파일만 옮기면 됩니다
- **불러오기** — 그 파일을 선택하면 장소가 복원되고 신규생성 카테고리로 전환됩니다. 기존에 만든 장소가 있으면 먼저 확인을 묻습니다

불러오는 파일은 내용을 검사한 뒤 반영합니다. 이름은 10자로 자르고, 그림은 파일 안에 직접 담긴 PNG·JPEG·GIF·WebP만 받습니다. 외부 주소를 가리키는 그림은 제외되며 몇 개가 빠졌는지 알려줍니다.

## 버튼

- **출발** — 처음 위치로 되돌린 뒤 주행 시작
- **처음** — 로봇을 출발점으로 (스티커는 유지)
- **지우기** — 현재 지도의 스티커 전체 삭제
- **PDF** — 현재 지도를 B3(500×353mm) 가로 PDF로 저장. 인쇄해서 실물 수업에 사용. 우측 상단에 카테고리 이름과 난이도 별이 함께 찍힙니다
- **속도 슬라이더** — 주행 속도 조절
- **그림 기호 on/off** — 색 위의 화살표 기호 표시 전환

## 실행

`index.html`을 브라우저로 열면 됩니다. PDF 저장 기능만 인터넷 연결이 필요합니다(jsPDF CDN).
